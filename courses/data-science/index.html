Frequently asked questions

What is the difference between Data Analytics and Data Science?

Data Analytics focuses on describing and explaining what happened using SQL and BI tools. Data Science extends that into prediction and automation using statistics and machine learning.

Do I need a maths background for the Data Science course?

Comfort with school-level maths is enough to start. The required statistics and linear algebra are taught within the course, in the context of the models that use them.

Does the Data Science course include real projects?

Yes. Every learner builds portfolio projects end to end, from data cleaning through modelling to a presentable result you can defend in an interview.
